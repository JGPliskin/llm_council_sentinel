## 计划概述
创建一个独立的测试脚本，用于检测指定OpenRouter模型的推理能力，不修改任何backend或frontend文件夹下的文件。

## 实现步骤
1. **创建测试脚本**：在根目录下创建`test_reasoning_chinese.py`文件
2. **配置模型列表**：使用用户提供的14个模型进行测试
3. **中文测试提示**：使用中文数学问题作为测试提示词
4. **保留原测试逻辑**：参考现有的`test_reasoning_models.py`结构
5. **保存详细结果**：将每个模型的推理过程和输出结果保存到JSON文件
6. **生成测试报告**：提供清晰的测试结果汇总

## 核心功能
- 测试每个模型是否支持reasoning参数
- 捕获并保存完整的推理过程
- 保存模型输出结果
- 支持流式和非流式测试
- 生成详细的测试报告

## 输出格式
- 控制台实时显示测试进度
- 详细结果保存到`reasoning_test_results_chinese.json`
- 包含模型成功/失败状态、推理支持情况、推理内容和输出内容

## 技术实现
- 使用asyncio进行异步测试
- 使用httpx调用OpenRouter API
- 从.env文件加载API密钥
- 处理各种API响应格式
- 错误处理和超时管理

这个计划确保在不修改任何现有代码的情况下，完成所有指定模型的推理能力测试，并保存完整的测试结果。
