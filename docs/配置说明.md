# 系统配置说明（Configuration Guide）

本文档详细说明可配置参数、默认值与影响范围。以 `backend/config.py` 与 `backend/main.py` 为准。

---

## 1. 配置文件总览

| 文件 | 作用 |
| --- | --- |
| `backend/config.py` | 后端核心配置（模型池、角色、超时、健康检查等） |
| `backend/main.py` | API 限流与输入长度限制 |
| `frontend/src/api.js` | 前端 API Base 与输入长度限制 |
| `.env` | 环境变量（API Key、Admin Token 等） |

---

## 2. 环境变量（.env）

| 变量名 | 必填 | 说明 | 默认值 |
| --- | --- | --- | --- |
| `OPENROUTER_API_KEY` | 是 | OpenRouter API Key | 无 |
| `NIM_API_KEYS` | 否 | Nvidia NIM API Keys，逗号分隔 | 空字符串 |
| `NIM_API_BASE` | 否 | NIM API Base | `https://integrate.api.nvidia.com/v1` |
| `NIM_RPM_PER_KEY` | 否 | NIM 每个 Key 的 RPM 限制 | `40` |
| `ADMIN_TOKEN` | 否 | 管理接口 Token | `secret-token` |

注意：后端当前为 debug 模式，`verify_admin` 放行所有请求，但前端仍会发送 `VITE_ADMIN_TOKEN`。

---

## 3. 后端核心配置（backend/config.py）

### 3.1 基础配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `OPENROUTER_API_URL` | `https://openrouter.ai/api/v1/chat/completions` | OpenRouter API Endpoint |
| `DATA_DIR` | `data/conversations` | 会话存储目录 |
| `COUNCIL_SIZE` | `3` | 默认议员数量 |

### 3.2 并发与超时

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `DEFAULT_CONCURRENCY_STAGE1` | `6` | Stage1 并发数 |
| `DEFAULT_CONCURRENCY_STAGE2` | `4` | Stage2 并发数 |
| `DEFAULT_STAGE1_TIMEOUT` | `120.0` | Stage1 单次调用超时 |
| `DEFAULT_STAGE2_TIMEOUT` | `180.0` | Stage2 单次调用超时 |
| `STAGE1_DEADLINE` | `180.0` | Stage1 总超时 |
| `STAGE2_DEADLINE` | `180.0` | Stage2 总超时 |
| `STAGE3_DEADLINE` | `180.0` | Stage3 总超时 |

### 3.3 错误分类（Fallback/Retry）

| 配置项 | 说明 |
| --- | --- |
| `REQUEST_ERROR_CODES` | 明确不可重试错误码集合 |
| `REQUEST_ERROR_KEYWORDS` | 请求层错误关键词（不可重试） |
| `MODEL_ERROR_KEYWORDS` | 模型层错误关键词（可重试） |

### 3.4 全局模型池（GLOBAL_MODEL_POOL）

字段说明：
- `id`：模型唯一 ID（建议带 `openrouter:` / `nim:` 前缀）
- `provider`：`openrouter` / `nim`
- `concurrency_limit`：该模型最大并发
- `category`：`fast` / `reasoning`
- `capabilities.thinking`：是否支持 Thinking Tool
- `capabilities.mode`：`tool` / `standard`

模型 ID 前缀规则：
- OpenRouter：`openrouter:<provider>/<model>`
- NIM：`nim:<provider>/<model>`

### 3.5 角色配置（COUNCILORS / CHAIRMAN）

每个 Councilor 字段：
- `id` / `name` / `avatar`
- `model`：默认模型
- `model_candidates`：候选模型池
- `persona_path`：Stage1 persona 文件
- `judge_persona_path`：Stage2 persona 文件
- `judge_system_prompt`：Stage2 系统提示
- `stage_limits.stage1` / `stage_limits.stage2`
- `auto_route_by_speed`：是否启用速度自动选路

Chairman 字段：
- `id` / `name` / `avatar`
- `model` / `model_candidates`
- `persona_path`
- `judge_system_prompt`
- `stage_limits.stage3`

### 3.6 健康检查与熔断

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `HEALTH_TTL_SECONDS` | `3600` | 健康缓存 TTL |
| `REFRESH_COOLDOWN_SECONDS` | `60` | 刷新冷却 |
| `FAILURE_THRESHOLD` | `2` | 连续失败阈值 |
| `BACKOFF_SECONDS` | `[120, 300, 900, 3600]` | 冷却退避梯度 |
| `PROBE_TIMEOUT_SECONDS` | `25.0` | 探测超时 |
| `HEALTH_PROBE_CONCURRENCY` | `4` | 探测并发 |
| `HEALTH_STARTUP_CHECK` | `False` | 启动时是否探测 |
| `HEALTH_CHECK_START_HOUR` | `10` | 定时检查开始小时 |
| `HEALTH_CHECK_END_HOUR` | `24` | 定时检查结束小时 |
| `HEALTH_CHECK_INTERVAL` | `7200` | 检查间隔（秒） |
| `HEALTH_CHECK_TIMEZONE` | `Asia/Shanghai` | 时区 |

### 3.7 速度自动选路

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `SPEED_ROUTE_SWITCH_ABS_MS` | `800` | 绝对阈值 (ms) |
| `SPEED_ROUTE_SWITCH_REL_PCT` | `0.30` | 相对阈值 (30%) |
| `EMERGENCY_PROBE_TTFT_THRESHOLD` | `20000` | 紧急探测 TTFT 阈值 |
| `EMERGENCY_PROBE_TTFT_MULTIPLIER` | `3` | TTFT >= EMA * 倍数 触发 |
| `EMERGENCY_PROBE_COOLDOWN_MINUTES` | `30` | 紧急探测冷却（分钟） |

### 3.8 ETA 预估

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `DEFAULT_ETA_CONFIG.default_ttft_ms` | `2000` | 首 token 估值 |
| `DEFAULT_ETA_CONFIG.default_generation_ms` | `5000` | 生成时间估值 |
| `DEFAULT_ETA_CONFIG.default_queue_wait_ms` | `1000` | 排队等待估值 |
| `DEFAULT_ETA_CONFIG.warmup_sample_count` | `3` | EMA 启动样本数 |

### 3.9 会话标题生成模型

`SUMMARY_MODEL_CANDIDATES`：用于生成会话标题的候选模型池。
